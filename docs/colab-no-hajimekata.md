# Google Colab の始め方 🚀

Google Colab(コラボ)は、ブラウザだけでPythonが書ける無料サービスです。インストール不要で、グラフもその場に表示されます。

## 手順(初回のみ・5分)

1. Googleアカウントでログインした状態で https://colab.research.google.com を開く
2. 「ノートブックを開く」画面が出たら **「GitHub」タブ** をクリック
3. 検索欄にこのリポジトリのURLを貼り付けて Enter:
   ```
   https://github.com/shuta060206-star/-
   ```
   - リポジトリが非公開(Private)の場合は「プライベート リポジトリも含める」にチェックを入れ、GitHub連携を許可する
4. ブランチを `claude/capabilities-discussion-is9zic` に切り替え、`lessons/lesson01_hajimete.ipynb` をクリックして開く

> うまく開けない場合の別ルート: GitHubのページで `.ipynb` ファイルを開き、右上の「⬇ Download raw file」でダウンロード → Colabの「ファイル」→「ノートブックをアップロード」で読み込む。

## 基本操作

| 操作 | やり方 |
|------|--------|
| セルを実行 | セルを選んで **Shift + Enter**(または左の ▶ ボタン) |
| セルを追加 | 上部の「+ コード」「+ テキスト」ボタン |
| 保存 | Ctrl + S →「ドライブにコピーを保存」(自分のGoogleドライブに保存される) |
| 全部やり直す | メニュー「ランタイム」→「セッションを再起動」 |

## 大事なポイント

- **Colabで編集した内容はこのGitHubリポジトリには自動反映されません。** 自分の作業は「ドライブにコピーを保存」した自分用ノートブックに残ります
- 一定時間放置するとランタイム(実行環境)がリセットされます。コードは残りますが、変数は消えるので、上から実行し直せばOK
- エラーが出たら、エラーメッセージごとコピーしてClaudeに送れば解説してもらえます
