# 非定常熱伝導 — Python学習&課題リポジトリ

Pythonをゼロから学ぶためのリポジトリです。目標は2つ:

1. **課題**: 一次元非定常熱伝導方程式を自分でプログラミングして解く
2. **その先**: プログラミングの中核構文を一通り身につけ、実務で書かれるコードを読める・書けるようになる
